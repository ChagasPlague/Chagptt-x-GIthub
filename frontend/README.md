# Frontend Universo IF Avalia

Na pasta frontend, execute `npm install`, `npm test`, `npm run build` e `npm run dev`. O catálogo foi extraído dos registros do importador backend/Catalogo.js. A URL do Apps Script é opcional e deve ser definida em `.env.local` somente após revisão. Os links dinâmicos dependem de suporte a parâmetros no HTML Service; integração ainda não homologada. Não há deploy automático.
