# Configuração Google
Mantenha a planilha privada, com abas Projetos, Codigos, Avaliacoes e Configuracao. Configure SPREADSHEET_ID nas propriedades do script, nunca no Git. Use clasp autenticado localmente, preserve .clasp.json e credenciais fora do Git. Após revisar o diff, use clasp push dentro de backend. Teste a URL /dev com conta editora ou uma implantação privada /exec. Nunca publique códigos originais. Mantenha votacao_aberta FALSE e modo DEMONSTRACAO. Atualize a implantação privada somente após testes. Configure VITE_APPS_SCRIPT_URL em frontend/.env.local. Para Pages, será necessário fornecer a URL aprovada no build. Acesso anônimo e publicação exigem autorização separada.
